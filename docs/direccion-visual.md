# La Gran Travesía de América — Biblia de Dirección Visual

## 1. Identidad artística

| Elemento | Dirección definitiva |
| --- | --- |
| Estilo | Countryballs clásico 2D |
| Formato | Vertical 9:16, 1080×1920 |
| Animación | 2D fluida con movimientos cinematográficos |
| Tono | 50% humor, 50% suspenso |
| Narración | Masculina, español latino neutro |
| Duración por episodio | 45–55 segundos |
| Edición | Cortes dinámicos y zooms |
| Subtítulos | Grandes, blancos, palabra destacada |

## 2. Reglas visuales obligatorias (no negociables)

1. Los personajes siempre son esféricos.
2. Colores y símbolos de la bandera correcta, sin errores.
3. Dos ojos blancos expresivos.
4. Sin brazos ni piernas humanos.
5. Accesorios solo cuando la historia lo requiera.
6. Ningún personaje cambia de forma entre escenas.
7. Las banderas no se confunden entre países.
8. Expresiones exageradas para facilitar el humor.

El estilo debe leerse como animación Countryballs tradicional, nunca como humanos disfrazados de países. Ver `docs/personajes/biblioteca-personajes.md` para las fichas de diseño de cada país — son la referencia que se reutiliza en todos los episodios para mantener continuidad.

## 3. Sonido y voz

| Elemento | Característica |
| --- | --- |
| Voz | Masculina adulta, español latino neutro |
| Personalidad | Narrador de aventuras |
| Emoción | Suspenso con humor, intensidad creciente hacia el final |

### Música y efectos por tramo (plantilla general de 53s)

| Tiempo | Sonido |
| --- | --- |
| 0–5s | Música épica y oleaje |
| 5–13s | Música de misterio |
| 13–18s | Viento, madera y olas |
| 18–23s | Turbulencias y relámpagos |
| 23–29s | Burbujas y sonido submarino |
| 29–41s | Música divertida y sonidos de reacción |
| 41–53s | Suspenso creciente y golpe final |

La música debe acompañar la emoción de cada escena, no sonar igual todo el episodio.

## 4. Reglas de edición y retención

- Nunca dejar una escena estática: usar acercamientos y pequeños movimientos de cámara.
- Alternar planos generales y primeros planos.
- Sincronizar expresiones con la narración.
- Efectos de sonido en los momentos clave; transiciones cortas.
- Los primeros 2 segundos deben generar curiosidad inmediata.
- Cada 3–5 segundos debe pasar algo visualmente interesante.
- No revelar todos los misterios; el final deja una pregunta abierta.
- El público debe sentir que sus comentarios pueden cambiar la historia.

## 5. Prompt maestro (para generación/producción asistida)

Ver `docs/episodio-01/prompt-maestro.md` para el prompt completo que fija rol, identidad visual/narrativa, formato técnico, continuidad y flujo de producción (storyboard → recursos → animación → voz → sonido → montaje).

## 6. Recomendaciones de producción

1. **Biblioteca de personajes primero.** Fijar el diseño de cada país antes de producir episodios (ver biblioteca de personajes) para que no cambien de apariencia entre videos.
2. **Producir por escenas, no de una sola vez.** Generar cada escena por separado y unirlas en edición; facilita corregir errores sin rehacer todo.
3. **Cerrar siempre con una decisión de la audiencia.** El final de cada episodio invita a votar/comentar qué ruta o destino sigue cada país, y esos comentarios alimentan el guion del episodio siguiente (ver `docs/estrategia-audiencia.md`).
